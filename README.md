# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from data loading and cleaning to visualization and reporting. The goal was to extract meaningful insights from the dataset and present them through interactive dashboards and business reports.

## Dataset

The dataset contains structured data used for analysis and reporting. It was loaded into Python for preprocessing and exploratory data analysis (EDA) before being stored and queried in PostgreSQL.

## Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* PostgreSQL
* SQL
* Power BI
* Gamma (for presentation creation)
* Jupyter Notebook

## Project Steps

### 1. Data Loading

* Imported the dataset into Python.
* Performed initial data inspection and validation.

### 2. Exploratory Data Analysis (EDA)

* Analyzed data structure and distributions.
* Identified trends, patterns, and potential issues.
* Created visualizations to understand key metrics.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicates.
* Corrected data types and formatting issues.
* Prepared data for analysis and reporting.

### 4. SQL Analysis

* Loaded cleaned data into PostgreSQL.
* Wrote SQL queries to answer business questions.
* Generated summary tables and key performance metrics.

### 5. Power BI Dashboard

* Connected Power BI to the processed dataset.
* Built interactive dashboards and visual reports.
* Included filters, KPIs, and trend analysis visuals.

### 6. Reporting & Presentation

* Created a business report summarizing key findings.
* Developed a presentation using Gamma to communicate insights and recommendations.

## Dashboard Highlights

* KPI Overview
* Trend Analysis
* Category Performance
* Interactive Filters and Slicers
* Business Insights Visualization

## Results

The project successfully transformed raw data into actionable insights through:

* Comprehensive data cleaning and analysis
* SQL-based business reporting
* Interactive Power BI dashboards
* Professional report and presentation for stakeholders

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Install required Python libraries:

```bash
pip install -r requirements.txt
```

3. Open and run the Jupyter Notebook for EDA and data cleaning.

4. Import the cleaned dataset into PostgreSQL and execute the SQL queries.

5. Open the Power BI (.pbix) file to explore the dashboard.

6. Review the report and Gamma presentation included in the project files.
